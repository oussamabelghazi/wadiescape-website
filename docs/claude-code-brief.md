# Brief — Build the Wadi Escape website

## Project
Build a static marketing website for **Wadi Escape**, a tailor-made travel agency operating in Oman. Domain already purchased: `wadiescape.com`. Target: clean, modern, single-page-feel site (or lightweight multi-page), mobile-responsive, fast-loading.

## Brand identity
- **Name:** Wadi Escape
- **Tagline:** "A blend of Oman's nature"
- **Color palette:**
  - Teal (primary): `#0F4C4C`
  - Gold (accent): `#D9A441`
  - Terracotta (accent): `#B5542B`
  - Cream (background): `#F6EFE3`
- **Logo files:** attached — `wadi-escape-logo.svg` (full lockup) and `wadi-escape-icon.svg` (icon only, for favicon/nav)
- **Tone:** premium-but-approachable adventure travel — authentic, not generic tour-operator style. All copy in English.

## Pages & structure
Use the structure and copy from the attached files:
- `wadi-escape-site-structure.md` — full page-by-page structure and layout notes
- `wadi-escape-website-copy.md` — final copy for every page (some placeholders in [brackets] still need real prices/hotel names — leave them clearly marked as TODO in the code if not yet filled)

Pages: **Home, Packages, Activities, About, Gallery, Contact** (Blog deferred to phase 2, don't build now).

## Images
Photos/videos of hotels, activities, and landscapes will be provided separately — build the layout with clearly marked placeholder image slots (correct aspect ratios per section: wide hero banner, square activity tiles, gallery grid) so real photos can be dropped in later without restructuring.

## Functionality
- Contact page needs a working quote-request form (fields listed in the copy doc) — since this is a static site, wire it to a simple form service (e.g. Formspree or Netlify Forms) rather than a backend.
- Sticky header with nav + persistent "Get a Quote" button linking to Contact.
- Footer with social links (Instagram, TikTok, Facebook, LinkedIn — handles: wadiescape) and copyright.

## Tech & deployment
- Plain HTML/CSS/JS (no heavy framework needed) — keep it simple and fast.
- Once built, help me deploy it to **Netlify** (or Vercel) and connect the `wadiescape.com` domain purchased on Namecheap (I'll need the DNS steps).
